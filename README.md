# LexiForge AI

A free vocabulary trainer that helps English learners turn passive vocabulary into active vocabulary.

## Status
Phase 1: dashboard, vocabulary input (add, edit, delete, duplicate check) and localStorage saving.
Games, the Vocabulary Engine and full progress tracking arrive in later phases.

## Cost
$0. HTML, CSS and JavaScript only. No paid APIs, no accounts, no backend.
Data is saved in your own browser (localStorage), so it is not shared between devices or browsers.

## Honesty note
LexiForge will use a rule-based Vocabulary Engine built from the words and meanings you enter.
It does not use generative AI and will not invent dictionary definitions.

## Run it
Open `index.html` in a browser, or use the VS Code "Live Server" extension.
